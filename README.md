# APE

Releases of **APE — Accounting & Payroll Engines**: Pay-E-Role, Tax-E and BIR Forms for DepEd personnel.

Download the latest installer from [Releases](../../releases/latest):

- **Windows:** `ape-setup-<version>.exe`
- **macOS:** `APE-mac-arm64.dmg` (Apple Silicon) or `APE-mac-x64.dmg` (Intel). The app is not signed with an Apple certificate: the first time, right-click the app and choose **Open**.

The source code is private. This repository only builds and publishes the installers.
